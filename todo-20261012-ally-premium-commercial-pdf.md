# Ficha premium del aliado: anualización, gráficas y ecosistema comercial — 2026-10-12

## Objetivo
Convertir la ficha técnica del aliado en una pieza comercial premium que conecte la oportunidad de carga con el valor anualizado para el aliado, una gráfica clara de escenarios y el potencial de activación de comercios aledaños.

## Implementación
Se incorporó una página con valor mensual y anualizado para los escenarios pesimista, realista y optimista, incluyendo una gráfica de barras determinística con cifras exactas y resaltado del escenario realista. Se añadió una página de ecosistema comercial con visual conceptual generado mediante Nano Banana Pro y mensajes sobre permanencia, consumo cruzado potencial, alianzas locales y posicionamiento del espacio.

Las oportunidades de consumo en comercios cercanos se presentan como potencial comercial no garantizado. No se inventan cifras de ventas de terceros ni se mezclan con la retribución del aliado; una cuantificación monetaria requerirá parámetros configurables del comercio participante.
